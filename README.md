# Ride Fare MLOps Platform

A production-level MLOps project that predicts ride fares using XGBoost and demonstrates the complete ML lifecycle.

## Tech Stack

- Python
- Scikit-learn
- XGBoost
- MLflow
- FastAPI
- Docker
- Kubernetes (EKS)
- GitHub Actions
- Prometheus + Grafana
